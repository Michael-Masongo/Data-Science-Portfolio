## Projects

### 1. [Credit Card Approval](Credit_Card_Approval_Project/)

- **Description:** This project was published on the Internet by a fellow data scientist, and I found it interesting. It is an application that predicts whether a person will get approved for a loan. After building the model, the creator also deployed it on Streamlit for others to access. I have added some improvements and changes to some sections. A predictive modelling project using supervised machine learning to analyze and forecast credit card approval outcomes based on applicant attributes such as income, employment, and credit history.

- **Tools Used:** Python, Jupyter Notebook, Pandas, Scikit-learn, Matplotlib, Seaborn.

- **Key insights:**

  1. **Approval Prediction Model:** Built and evaluated classification models (e.g., Logistic Regression, Random Forest, Decision Trees, Gradient Boosting, Gaussain Naive Bayes) to predict the likelihood of credit card approval with high accuracy.
  2. **Feature Importance:** Identified key factors influencing approval, such as income level, age, employment status, dwelling place, and ownership of property.
  3. **Data Processing & Imputation:** Handled missing values, encoded categorical variables, and performed feature scaling to improve model performance.
